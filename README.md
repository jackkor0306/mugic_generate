# 🎵 음악 스튜디오

로컬 PC에서 실행되는 AI 작사·작곡 스튜디오입니다. Claude Opus 4.8이 가사를 쓰고, 악보(ABC notation)를 작곡·편곡하며, 그 악보를 재료로 이펙트가 적용된 WAV 음악파일을 만들어 줍니다.

## 실행 방법

**`음악스튜디오.bat` 파일을 더블클릭**하면 끝입니다.
- 서버가 켜지고 브라우저(http://localhost:3789)가 자동으로 열립니다.
- 검은 콘솔 창은 스튜디오의 엔진입니다. **닫으면 스튜디오가 종료**되니 사용 중에는 열어 두세요.
- 바탕화면의 「음악 스튜디오」 바로가기로도 실행할 수 있습니다.

## 사용 흐름

1. **새 곡 만들기** — 방향/주제, 분위기, 편성 악기, (선택) 참고 가사를 입력합니다.
2. **AI 작사** — Claude가 섹션 구조([Verse]/[Chorus]...)를 갖춘 가사를 씁니다. 피드백을 적어 재생성하거나 직접 수정할 수 있습니다.
3. **AI 작곡** — 가사를 바탕으로 멀티 악기 **악보를 먼저** 만듭니다(보컬 멜로디 + 악기별 보이스, 텐션 코드 심볼 포함).
   - 기본 편성: 피아노(메인) · 세컨 피아노 · 일렉 기타 · 드럼 (자유롭게 변경 가능)
   - 피아노류 악보는 높은음자리표(오른손) + 낮은음자리표(왼손) **그랜드 스태프**로 작성됩니다.
   - 멜로디와 반주가 동시에 울릴 때 단2도/장2도 불협화음이 나지 않도록 검증하며 작곡합니다.
4. **음악파일 생성** — 악보를 신디사이저로 연주하고 리버브·컴프레서 등 이펙트를 입혀 **WAV 파일**로 다운로드합니다. MIDI 파일도 받을 수 있습니다.
   - ⚠️ 보컬은 신디사이저 음색(허밍/합창 느낌)으로 연주됩니다. 로컬 환경에서는 가사를 실제 목소리로 부르는 가창 합성이 불가능합니다.
5. **악기별 반주 악보** — 편성한 악기마다 독립된 파트 악보를 탭으로 확인하고, 파트별 WAV/ABC 파일로 저장할 수 있습니다.
6. **참고 자료 첨부** — 곡 상세의 「📎 참고 자료」에 기존 음악/악보 파일을 첨부하면, 다음 작사·작곡(재생성) 때 AI가 분석하여 반영합니다.
   - 악보 파일: `.abc` `.xml/.musicxml`(MusicXML) `.mid/.midi`(MIDI — 음표를 자동 해석) `.txt`
   - 악보 이미지: `.png` `.jpg` 등 — Claude가 이미지 속 악보를 직접 읽습니다 (사진/스캔 OK)
   - 오디오: `.mp3` `.wav` 등 — 길이·추정 템포(BPM)를 분석해 참고 정보로 전달 (멜로디 추출은 안 됨, 메모로 원하는 바를 적어주세요)

모든 곡은 **회차(1회차, 2회차...)로 목록 관리**되며, 상세 화면에서 수정·재생성이 가능합니다. 가사/악보를 다시 만들 때마다 이전 내용은 **버전 히스토리**에 남아 언제든 복원할 수 있습니다.

## 🎤 실제 목소리로 부르게 하기 (원클릭 AI 가창)

곡 상세 → 오디오 카드의 **「🎤 AI 가창 렌더링 시작」** 버튼 하나면 AI 가수(Nishiren, 한국어 지원 DiffSinger)가 가사를 실제로 발음하며 노래한 WAV가 만들어집니다. CPU 렌더링이라 곡 길이에 따라 몇 분 걸립니다. 완료되면:
- 화면에서 바로 재생해볼 수 있고,
- **「🎬 완성곡 WAV 만들기」**를 누르면 AI 보컬 + 반주(MR)를 자동으로 믹스한 완성곡이 다운로드됩니다.

내부 구조: 악보의 보컬 파트 → USTX 프로젝트 자동 변환 → OpenUtau 엔진을 UI 없이 구동하는 자체 헤드리스 렌더러(`tools/OuRender`)로 가창 합성. 세밀하게 다듬고 싶으면 「UST 내보내기」로 받아 OpenUTAU에서 직접 편집할 수도 있습니다.

**설치**: 이 PC에는 이미 설치되어 있습니다. 다른 PC에서는 PowerShell로 `tools\setup-vocal.ps1`을 실행하면 OpenUtau + 한국어 AI 가수 + 렌더러가 자동 설치됩니다(약 1GB 다운로드).

> 참고: GPU(그래픽카드)가 있는 PC라면 ACE-Step, DiffRhythm 같은 Suno류 로컬 곡 생성 AI도 선택지가 되지만, 현재 PC 사양(내장 그래픽)에서는 OpenUTAU + DiffSinger가 현실적인 방법입니다.

## 필요 조건

- Windows + Node.js (설치되어 있음)
- Claude Code 로그인 상태 (Opus 4.8 사용 가능한 플랜)
- 음원(WAV) 생성 시에만 인터넷 연결 필요 — 악기 사운드폰트를 온라인에서 불러옵니다. 작사/작곡은 Claude 호출을 위해 인터넷이 필요합니다.

## 데이터 저장 위치

- 모든 곡/가사/악보/버전은 파일 DB(SQLite)인 `data/studio.db` 한 파일에 저장됩니다.
- 백업하려면 `data` 폴더만 복사하면 됩니다.

## 문제 해결

- **작사/작곡이 실패해요** → 화면의 오류 메시지를 확인하고 다시 시도하세요. Claude Code 로그인이 풀렸다면 터미널에서 `claude` 실행 후 재로그인하세요.
- **포트가 이미 사용 중** → 이미 스튜디오가 실행 중입니다. 열려 있는 브라우저 탭을 사용하세요.
- **악보에 경고가 떠요** → AI가 만든 ABC 표기의 사소한 문제입니다. 「재작곡」 또는 「ABC 소스 편집」으로 해결할 수 있습니다.
